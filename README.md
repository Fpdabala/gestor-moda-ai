# GestorModa AI - Sistema Inteligente de Gestão de Vendas, Condicionais e Engajamento
Sistema web desenvolvido para vendedores autônomos e pequenos lojistas de vestuário gerenciarem clientes, catálogo de peças, sacolas condicionais e métricas financeiras com suporte de Inteligência Artificial.

## 🛠️ Stack Tecnológica
- **Backend:** C# / .NET (ASP.NET Core)
- **Persistência / Banco de Dados:** PostgreSQL (Entity Framework Core)
- **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
- **Inteligência Artificial:** Google Gemini API

## 📌 Escopo do Projeto (Entrega 1)
- CRUD completo de Clientes e Peças
- Controle de saída e retorno de Sacolas Condicionais
- Dashboard analítico com KPIs financeiros e operacionais
- Assistente de IA para geração automatizada de mensagens comerciais para WhatsApp
